# Start — in drei Schritten zu deinem Assistenten

**Du brauchst:** ein bezahltes Claude-Konto (Pro oder höher) und Claude Code auf deinem Rechner
(Mac, Windows oder Linux). Die kostenlose Claude-Version reicht dafür nicht.

1. **Ordner ablegen.** Entpacke diesen Ordner an einen Ort, an dem er bleiben darf
   (zum Beispiel „Dokumente"). Das ist ab jetzt das Gedächtnis deines Assistenten.
2. **Claude Code in diesem Ordner öffnen.** Terminal: in den Ordner wechseln und `claude` eingeben.
3. **Diesen Satz eingeben:**

   ```
   /einrichten
   ```

Danach führt dich dein Assistent durch ein kurzes Interview (etwa zehn Minuten). Zum Schluss
tippst du **/morgen** — und er plant mit dir den Tag.

Hilfe und Austausch: in der Gruppe (Link in deiner Anleitung).
